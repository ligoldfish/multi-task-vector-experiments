## 必须保留的解释边界

1. **MBPP容量是真约束。**300+37+37用尽374条；完整回答、修复prompt、表面控制的联合长度过滤或真实gold验证失败都会减少可用池。默认严格失败并写`capacity_preflight.json` / `rejected.jsonl`，任何调整都必须采用用户批准的补充协议并记录实际数量。
2. **联合非binary达标不是严格正确率。**数学/逻辑/代码可以用二值正确；翻译/改写/摘要必须使用显式、预锁的指标阈值。句级阈值与corpus主结果不同，两个结果都保留。
3. **corpus结果不能用句分平均代替。**bootstrap只缓存单样本执行或语义证据，chrF++/BLEU/iBLEU每个重采样面板重新计算corpus值。
4. **subprocess资源限额不是安全边界。**正式代码评测使用专用低权限worker；如平台支持Docker，容器后端禁网、只读、非root、限资源。执行后端与限制写入每条证据。
5. **未正式运行不等于实验通过。**本轮工程实现不证明共享成分、正迁移、组合收益、未见任务收益，也不能保证八卡硬件或任一卡的实际容量。
6. **原文到NPU的变化有明确授权。**模型、精度、任务、损失、batch和方法公式继续遵守原协议；平台切换来自本轮用户要求，不用GPU容量估计冒充NPU测量。
7. **资产内容与样本文件必须可复核。**HF保存目录/原始文件记录内容SHA；每次读取准备好的split重新验证实际JSONL的SHA和数量。语义模型内容指纹公开于`semantic_asset_fingerprint`，实际句级证据保存版本和逐文件清单；bootstrap只聚合缓存。

MBPP官方完整task ID范围按[作者官方说明](https://github.com/google-research/google-research/blob/master/mbpp/README.md)加载；IWSLT英德方向与官方split按[数据发布说明](https://huggingface.co/datasets/IWSLT/iwslt2017)保留。
