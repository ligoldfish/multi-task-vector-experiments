# 官方合并基线及本项目适配

实现：`src/task_vector/baselines.py`；逐文件 commit、下载 URL、SHA256 见 `third_party/baseline_sources.json`。原始文件与许可证分别保存在 `third_party/TIES`、`third_party/TSV`、`third_party/KnOTS`。本项目保留作者算法，转换的是输入/输出容器和执行设备；没有把实验自身的跨任务 SVD 投影重新命名成文献基线。

| 基线 | 作者源码定位 | 本项目固定变体 |
|---|---|---|
| TIES | prateeky2806/ties-merging，commit `44e7891fc84f3de7e4caa52664cd864ca3715e91`，`src/utils/merge_utils.py` | magnitude top-k reset、mass sign election、全坐标 global majority 填零符号、disjoint mean；默认名义保留 .2，强度由外层统一预算选择 |
| TSV-M | AntoAndGar/task_singular_vectors，commit `a6c97188f7aa0bb20753de4f2939be89dd64f1c3`，`src/utils/TSVM_utils.py:compute_and_sum_svd_mem_reduction` | 按模块矩阵 SVD，每任务保留 `floor(min(out,in)/T)`，拼接 U/S/V，再分别对 U、V 求 polar 正交因子后重建；不使用其它同仓库压缩、eigen 或 lossless 变体 |
| KnOTS-TIES | gstoica27/KnOTS，commit `baa35e85768b8841820d35edc3e41b25304248c5`，`task_merger.py:SVDMerger.apply_svd`、`masking_ops.py` | 实际矩阵更新横向拼接联合 SVD，保留奇异值 >1e-5，得到共同 U 与各任务 sV；在全部模块 sV 坐标上统一做 TIES mask、disjoint mean，再乘共同 U；关闭 DARE |

所有 LoDA 基线输入均为真实应用了 `0.5`、Lambda 与 Isolated 系数的 DeltaW，不能拼 A/B 后做符号裁剪。TIES 可作为 activation 坐标适配，结果明确记录这种适配；TSV 与 KnOTS 仅用于 parameter 矩阵。

TIES 的作者阈值是 `abs >= kthvalue(d-floor(d*K))`。因此名义保留 20% 并不保证恰好 20%，边界和并列值可能保留更多；代码记录实际保留率，不改用 exact top-k。全局符号投票和裁剪都跨全部模块；逐层执行会改变算法。K=1 时显式表示不裁剪，修复原 TIES 阈值下标为零的边界，遵循 KnOTS 作者边界处理。

TSV-M 的秩基于矩阵维度，不能因为 LoDA 输入秩最多 16 就把作者的 `floor(d/T)` 改成 `floor(16/T)`。即便含零奇异值方向，原算法的 polar 步骤仍按原维度执行。谱分解在 CPU float64 运行以避免 Ascend 未支持算子；结果存 FP32，数学过程不变。KnOTS 遵循作者联合 SVD float64、U/S/V 先转 FP32 再构建 sV 的顺序。

不在合并后偷偷截断回 rank16。TIES 逐坐标操作可以使更新成为满秩，因此以完整矩阵和恒等因子精确保存；TSV/KnOTS 保存计算所得全部因子。NPU 评测需要实测内存，不能通过未声明的秩截断降低开销。范数匹配、强度/权重搜索和同预算比较由实验驱动统一施加，并在主结果中报告原始和范数匹配版本。

验证使用 tiny 矩阵，将固定作者原文件中的纯函数通过 AST 单独加载，与本实现逐元素比对；覆盖 TIES 全局阈值、矩形 TSV-M、KnOTS 联合 SVD/sV mask/重建，以及因子等价重参数化和零更新。没有加载作者环境或执行其训练脚本。
