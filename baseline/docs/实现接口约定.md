# 实现接口（2026-10-10）

用户已批准补充：E5原任务面板+双任务联合输入/分别评分/联合成功；MBPP官方train300/37/37，test256；E6四折+SAMSum。LoDA token二阶矩均值、A=基转置/sqrt3、FP32 B、固定基座S重标定lambda3、raw/post均存post主；每epochNLL选点；主迁移强度1，调参结果另列。NPU Ascend910B八卡，用户报总显存64G（实测探针核实），CANN8.5.0-a3、torch/torch_npu2.8.0，所有资产在/opt/dpcvol/datasets。并行独立实验，单run batch16不变。

包位于src/task_vector；根代理拥有config.py/runtime.py/representations.py/io.py/analysis.py/baselines.py/suite.py/cli.py/runner.py/部署与总文档。其它代理只写其分配模块与相应tests，避免重叠。

Representation见representations.py：space activation或parameter；activation values键为HF named_module路径model.layers.14，值FP32向量；parameter factors键model.layers.N.self_attn.q_proj/k_proj/v_proj，list[LowRankFactor(B,A)]，**B含所有真实缩放**；metadata记录来源。save/load为纯张量payload，torch weights_only兼容。

数据接口（数据代理负责data.py/prompts.py/metrics.py/code_execution.py/joint.py）：Sample dataclass字段id,task,prompt,target,group_id,official_split,metadata(dict)，to_dict/from_dict；prepare_dataset(config,tokenizer,output_dir)->manifest字典，并保存每任务train/tune/discovery/test.jsonl；load_samples(data_root,task,split)->list[Sample]。render_prompt(tokenizer,sample,variant='canonical')->str，apply_chat_template nonthinking，保留完整assistant prefix；encode_sample(tokenizer,sample,variant='canonical',max_prompt=512,max_target=512)->dict含input_ids/labels/prompt_length/id（完整回答含EOS），超长抛ValueError。指标score_predictions(task,rows,config)->dict，包含metrics主辅、sample_scores可用于std、逐样本rows；输入row包含id,group_id,prompt,target,prediction,metadata。metrics[primary_metric_name]一致主名：accuracy/chrF++/iBLEU/pass_all/rougeL。联合样本构建build_joint_samples(samples_by_task,seed,count)->list[Sample]，task='joint'，metadata含原任务样本，评分保留各任务单位，只有binary correctness才定义joint success，非binary需显式预定义判据且标注。离线数据原始目录约定config.data.sources[task]可指HF保存目录或rawJSON/JSONL，必须保存官方split来源，不自动混集。

模型/训练接口（LTV代理负责modeling.py/ltv.py/losses.py/training.py/evaluation.py）：load_model(config,device)->(model,tokenizer)；collate_encoded(list[dict],pad_token_id,device)->dict包含input_ids,attention_mask,labels,prompt_positions；answer_nll(logits,labels)->[batch]样本均值；LTVIntervention(model,Representation) context manager带set_positions(tensor)、set_prefill(bool)；generic intervention_context(model,representation,positions=None)支持parameter非训练更新wrapper；generate_predictions(model,tokenizer,samples,representation,config,device,variant='canonical')->list[dict]完整逐样本输出含truncated；evaluate_nll(model,tokenizer,samples,adapter,config,device)->float；train_task(model,tokenizer,train_samples,tune_samples,*,task,route,seed,output_dir,config,device,subspaces=None,initial_representation=None)->dict{raw_path,post_path,best_nll,steps}。config用嵌套普通dict，模型字段config['model']，训练config['training']（ltv/loda公共字段+wd分支）、LoDA config['loda']。方法内自主初始化adapter，LTV不依赖LoDA分解；LoDAAdapter从loda.py导入，GAO从gao.py。train_task额外训练状态完整保存optimizer/scheduler/RNG并支持resume，从最佳NLL恢复后导出raw/post。所有小测试可以CPU tiny随机模型，不下载正式模型。

LoDA接口（LoDA代理负责loda.py/subspaces.py/gao.py/sequential.py）：collect_statistics(model,tokenizer,samples,config,device)->dict[module_layer_key,Tensor2048x2048]，layer_key='model.layers.N'，基座prompt-only样本/位置来源存metadata；build_subspaces(stats_by_task:dict[task,dict[layer,Tensor]],task,config)->dict[layer,dict{A_G,A_I,S_self,S_other,lambda}]；LoDAAdapter(model,subspaces,train_general_a=False,isolated_enabled=True)，nn.Module/context manager，parameters()只列adapter参数、set_recalibrated(bool)、representation(task,seed,version='raw'|'post')->Representation；optimizer_state由训练层负责；gao_step(parameters,optimizer,group1,group2,loss_fn,rho_max=.05,clip_norm=1.,scheduler=None,generator=None)->dict；group为8个encoded样本，loss_fn(group)返回可backward完整组均值，训练层loss_fn负责micro2逐组累积可用gao回调接口另行协商。first sequential stage训练A_G+B_G，isolated关闭；其它阶段统计从当前模型抽，合并更新继承theta。sequential训练driver可依赖training.train_task并返回每stage记录，单列报告。
