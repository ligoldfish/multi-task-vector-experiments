# 加速版部署与实验边界

本版对应 2026-10-13 的工程加速重启。默认采用用户确认的 `validated`：只用源任务 tune 样本选择推理 batch，保持方法、数据和评分一致，允许 BF16 计算形状引起正常 token 差异。完整原始方案及已接受的补充协议继续适用。

## 执行方式的变化

| 环节 | 本版实现 | 保持的要求 |
|---|---|---|
| 生成评估 | 每卡一个持久进程，分片并行；全部分片完成后恢复原 ID 顺序、统一评分 | 同一模型、干预、样本、greedy、KV cache、EOS 与生成长度 |
| 推理 batch | 源任务 tune 中确定性选择最多 8 条不同长度样本，测试 1/2/4/8，选择有效候选中吞吐最高者 | 不按 test/discovery 的评分或答案质量选择；同一任务/提示变体跨路线、条件、seed 固定策略 |
| 留出与联合任务 | 留出目标、SAMSum、联合输入保持 batch=1，参与八卡分片 | 不读取留出目标 tune 来选参数 |
| 生成循环 | token 暂存在设备，减少逐 token/逐行回传与同步 | 相同输入、缓存位置和停止语义；检查非有限 logits |
| 后续独立训练、层消融 | 同一已允许阶段内使用八卡任务池 | micro batch=2、梯度累积=8、有效 batch=16、GAO 两半和两次更新不变 |
| 顺序对照 | 不同 seed/order 并行；每个顺序内部四阶段依次训练、合并 | 预测读取已提交的原生 dtype 合并 QKV 权重，不以重构近似替代 |
| bootstrap | 缓存官方 SacreBLEU 2.5.1 整数充分统计，再聚合重采样 | 相同 2000 次配对/分组重采样、RNG 顺序、语料级 BLEU/chrF/iBLEU、分布与 CI |

训练 batch 不增大；增大的是推理 batch。阶段门禁、严格首轮记录、控制组与扩评范围保留，不提前执行尚未获门禁允许的实验。无需为 1.7B 模型引入模型切分或 DDP。

`validated` 记录相对 batch=1 的 token/停止结果差异，不以普通 BF16 差异否决候选。候选必须满足有限 logits、完整 ID 覆盖、固定预算与有效停止契约。OOM 候选排除；实际面板明确 OOM 或非有限 logits 可回退 batch=1 并记录，batch=1 仍无效则报错。其他错误不静默回退。回退记录用于异常恢复，不能当作统一 batch 的性能数据。

可选 `strict` 固定 batch=1，仍享有八卡分片和统计加速；`audited` 为每个实际面板额外执行 batch=1 审计，有差异使用参考输出，开销较高。默认是 `validated`。

## 1. 上传与完整性检查

在现有 Notebook 文件页将 ZIP 与 `.zip.sha256.txt` 上传到 `/home/work/user-job-dir/app`。以下命令仅创建新目录，拒绝覆盖已有目录。

```bash
bash <<'BASH'
set -eo pipefail
cd /home/work/user-job-dir/app
python - <<'PY'
import hashlib, json, stat, zipfile
from pathlib import Path, PurePosixPath
source = Path("task-vector-accelerated-20261013.zip")
checksum = Path("task-vector-accelerated-20261013.zip.sha256.txt")
target = Path("task-vector-accelerated-20261013")
expected = checksum.read_text(encoding="utf-8-sig").split()[0].lower()
if hashlib.sha256(source.read_bytes()).hexdigest() != expected:
    raise SystemExit("ZIP SHA256 不匹配，停止")
if target.exists():
    raise SystemExit(f"目录已存在，保留并停止：{target}")
with zipfile.ZipFile(source) as archive:
    names = archive.namelist()
    if len(names) != len(set(names)):
        raise SystemExit("ZIP 有重复路径，停止")
    for item in archive.infolist():
        relative = PurePosixPath(item.filename)
        if relative.is_absolute() or ".." in relative.parts or "\\" in item.filename or stat.S_ISLNK(item.external_attr >> 16):
            raise SystemExit(f"ZIP 路径不合规：{item.filename}")
    manifest = json.loads(archive.read("PACKAGE_MANIFEST.json"))
    if set(names) != set(manifest["files"]) | {"PACKAGE_MANIFEST.json"}:
        raise SystemExit("ZIP 文件清单不匹配，停止")
    for name, digest in manifest["files"].items():
        if hashlib.sha256(archive.read(name)).hexdigest() != digest:
            raise SystemExit(f"文件哈希不匹配：{name}")
    archive.extractall(target)
print("ZIP_SHA256=PASS")
print("VERIFIED_FILES=" + str(len(manifest["files"])))
print("CODE_DIR=" + str(target.resolve()))
PY
BASH
```
